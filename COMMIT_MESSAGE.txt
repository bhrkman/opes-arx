THE FRONT DOOR IS THE GAME

The site root held a landing page, which was replaced with a redirect, and the redirect did
not take — the live site went on serving the old card page through three uploads.

A redirect is a SECOND FILE that has to be uploaded, cached and trusted before anybody
reaches anything, and every one of those is a place to fail. So there is no redirect now.

- sim/build_corp.cjs writes the built page to index.html and viewers/index.html as well as
  viewers/the_corp.html — the same bytes. The root IS the game.
- The harness compares index.html to viewers/the_corp.html byte for byte, and fails if a
  landing page or a redirect ever stands in front of it again.
- .nojekyll included so GitHub Pages serves the tree as-is.

Everything else in this bundle is the quirk work already described.
